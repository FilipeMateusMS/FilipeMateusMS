## 🚀 Projetos em Destaque

### 🛒 E-Commerce Monolítico

Sistema de e-commerce desenvolvido utilizando **Java 21 e Spring Boot 3**, seguindo boas práticas de arquitetura em camadas, segurança, persistência de dados e testes automatizados.

**Principais recursos:**

- Autenticação e autorização com Spring Security + JWT.
- Controle de acesso baseado em Roles (USER e ADMIN).
- Persistência com Spring Data JPA e MySQL.
- Cache de respostas utilizando Redis.
- Conversão entre entidades e DTOs com MapStruct.
- Testes automatizados com JUnit e Mockito.
- Documentação da API com Swagger/OpenAPI.
- Containerização com Docker e Docker Compose.

**Tecnologias:** Java 21, Spring Boot, Spring Security, JWT, Spring Data JPA, Hibernate, Redis, MySQL, MapStruct, Lombok, JUnit, Mockito e Docker.

🔗 [Acessar repositório](https://github.com/FilipeMateusMS/e-commerce-monolith)

### ⚙️ E-Commerce em Microsserviços

Projeto de e-commerce baseado em arquitetura de microsserviços, com foco em escalabilidade, comunicação assíncrona, segurança e observabilidade.

**Principais recursos:**

- Descoberta de serviços com Eureka.
- API Gateway com Spring Cloud Gateway.
- Configuração centralizada com Spring Cloud Config.
- Comunicação assíncrona utilizando Apache Kafka.
- Persistência relacional com PostgreSQL.
- Persistência NoSQL com MongoDB.
- Rastreamento distribuído com Zipkin.
- Autenticação e autorização com Keycloak.
- Envio de e-mails com Spring Mail.
- Ambiente containerizado com Docker.

**Tecnologias:** Java 21, Spring Boot, Spring Cloud, PostgreSQL, MongoDB, Apache Kafka, Zookeeper, Keycloak, Zipkin e Docker.

🔗 [Acessar repositório](https://github.com/FilipeMateusMS/ecommerce-microsservices)
